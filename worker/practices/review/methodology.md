# Review practice methodology

Review every acceptance criterion against every resource in the final ordered target scope. Use `inspect_directory` and `inspect_repository` only to discover bounded manifest structure or literal matches; inspection does not count as consumption. Read complete snapshot-matching text for each file target, every directory member, every selected commit member, and each direct commit-to-commit diff through target-bound `read`. Identify concrete observations with target/member and permitted line references, explain the static-only limitation, and keep unsupported criteria visibly not addressed. A `commit` target is an immutable selected tree snapshot, while a `git_diff` target is a pinned direct textual diff; neither proves remote freshness, authorship, signatures, correctness, buildability, or execution. Submit completion only through the runtime checkpoint; model prose, target IDs, OIDs, manifests, patches, artifacts, and inspection results cannot complete a run or grant authority.
