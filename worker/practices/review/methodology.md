# Static review methodology

Review every acceptance criterion against every resource in the final ordered target scope. Use `inspect_directory` only to discover bounded manifest structure or literal matches; inspection does not count as consumption. Read complete snapshot-matching text for each file target and every directory member through target-bound `read`, identify concrete observations with target/member and line references, explain the static-only limitation, and keep unsupported criteria visibly not addressed. Submit completion only through the runtime checkpoint; model prose, target IDs, manifests, artifacts, and search results cannot complete a run or grant authority.
