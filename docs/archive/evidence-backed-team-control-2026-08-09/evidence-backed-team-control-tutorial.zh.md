# Tiangong 可信团队控制：从一条需求开始

这是一套面向开发人员、但不要求读过 Tiangong 代码的入门教材。

课程不会一上来罗列对象、字段定义或安全术语。我们会跟着一条真实需求，先看最自然的做法会遇到什么问题，再给解决办法起正式名字，最后才阅读数据结构和少量伪代码。

完整目录和阅读说明见：

> [开始学习：课程目录](evidence-backed-team-control-tutorial/README.md)

目标架构的正式定义仍以 [`evidence-backed-team-control.md`](evidence-backed-team-control.md) 为准。教程负责帮助理解，不能替代正式设计中的约束。
