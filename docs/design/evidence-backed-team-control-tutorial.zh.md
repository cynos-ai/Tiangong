# Tiangong 可信团队控制：从一条需求走到安全交付

这是一套从零开始的中文教程。它写给需要理解、实现或评审 Tiangong 的开发人员，不要求你预先读过代码，也不要求你先背对象和状态名。

全课程跟随同一条“取消订单”需求。每个单元都先制造一个真实问题，再解释普通做法为什么不够，最后才引入最小的数据和代码边界。每章末尾都有一份**累积小结**：它不是只复述本章，而是把从第一章到当前位置已经建立的整套心智模型重新串起来。

完整目录、案例说明和两种阅读路线见：

> [开始学习：课程目录](evidence-backed-team-control-tutorial/README.md)

正式合同以 [`evidence-backed-team-control.md`](evidence-backed-team-control.md) 为准。本教程解释目标设计，不声称运行时代码已经全部实现，也不把案例中的做法规定成所有团队必须照搬的固定流程。
